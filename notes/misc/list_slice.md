# Тема: срез списка

## 1. Определение

**Срез списка (slice)** — это способ взять часть списка (подсписок) по правилу «от индекса A до индекса B». Он создаёт новый список, а исходный не меняется.

**Синтаксис:**
```
название_списка[start:stop:step]

start — с какого индекса начать (включительно);
stop — до какого индекса (НЕ включая его);
step — шаг (по умолчанию 1);
```

Любую часть можно пропустить. Работает это через квадратные скобки с двоеточием.

## 2. Главное свойство
```
срез = новый список
```
Срез копирует элементы в новый список. 
Поэтому `arr[:]` часто используют как быстрый способ скопировать список.

⚠️ **Копия поверхностная:** если внутри списка лежат вложенные списки, они копируются «по ссылке», а не полностью. Но для чисел/строк это неважно.

## 3. Примеры нахождения среза
Исходный список:
```
arr = [10, 20, 30, 40, 50, 60, 70, 80]
#       0   1   2   3   4   5   6   7
```

|Срез|Результат|Смысл|
------------------------------------
|`arr[:]`|весь список|копия целиком|
`arr[:3]`	[10, 20, 30]	первые 3
`arr[3:]`	[40, 50, 60, 70, 80]	с индекса 3 до конца
`arr[2:5]`	[30, 40, 50]	с индекса 2 по 4 (5 не входит)
`arr[::2]`	[10, 30, 50, 70]	каждый второй
`arr[::-1]`	перевёрнутый	шаг −1
