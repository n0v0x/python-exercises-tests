# Misc

Hands-on practice with core Python: data types, built-in data structures,
and the language features I use every day but want to know cold.

Each module is a small, self-contained file with typed functions, docstrings,
and tests next to the code in `tests/fundamentals/`.

## What's covered

- **Data types** — `int`, `float`, `bool`, `str`, `None`, numeric edge cases
  (float precision, integer division, overflow behaviour)
- **Data structures** — `list`, `tuple`, `dict`, `set`, and when to use which;
  `collections` (`deque`, `Counter`, `defaultdict`, `namedtuple`)
- **Iteration & comprehensions** — list/dict/set comprehensions, generators,
  `enumerate`, `zip`, `itertools`
- **Functions** — positional/keyword-only args, `*args`/`**kwargs`, closures,
  decorators, `functools`
- **Strings** — slicing, formatting (f-strings), encoding basics
- **Mutability & copying** — shallow vs deep copy, aliasing, why tuples are hashabl
